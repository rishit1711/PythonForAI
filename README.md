# Python for AI Development 🐍

This repository documents my journey of learning Python for AI application development through hands-on coding and practical implementations.

The goal is to build AI-powered applications using Python while keeping Java as my primary backend language.

## 📚 Learning Roadmap

- **Python Fundamentals:** Syntax, data structures, OOP, modules, and testing.
- **Backend Development:** FastAPI, Pydantic, async programming, and REST APIs.
- **LLM Applications:** LLM APIs, structured outputs, error handling, and reliability.
- **RAG & Retrieval:** Embeddings, vector databases, chunking, and evaluation.
- **Tool Calling:** AI workflows, tool integration, and safety.
- **Integration:** Connecting Python AI services with Java/Spring Boot, Docker, and CI.

## 🛠️ Tech Stack

Python · FastAPI · Pydantic · pytest · LLM APIs · RAG · Vector Databases · Java · Spring Boot · Docker · Git
